# 寂光寺行動應用程式（jiguang-app）

寂光寺專屬 iOS／Android App，將既有官方網站服務行動化，並整合個人業障查詢、AI 分類、推播、法音梵唄、電子書與交通資訊等功能，打造一站式數位修行輔助平台。

> 詳細需求規格請見 [寂光寺App規格書 2.md](./寂光寺App規格書 2.md)（文件版本 v1.1，2026-09-21）。

---

## 專案目標

- 將寺方網站內容轉為適合手機操作的原生／混合式 App
- 提供個人化業障查詢與 AI 輔助分類，強化自我修行覺察
- 建立信眾與寺方管理者之間匿名、安全的互動管道
- 以推播傳遞法會資訊與每日佛學智慧，提升黏著度
- 提供法音梵唄播放、電子經書閱讀與到寺交通資訊

### 功能簡述

- **網站行動化**：寺院介紹、活動、公告等內容以行動優先介面呈現，並與網站內容同步
- **業障查詢**：會員登入後查詢個人業障紀錄與歷史趨勢，資料僅本人與授權管理者可見
- **AI 分類**：依寺方確認之分類架構（如五毒）自動歸類；分類結果頁須具備防截圖、防錄影、防拷貝機制（上線強制項）
- **匿名心得**：信眾匿名分享修行心得，管理者可回覆與審核
- **推播通知**：共修法會資訊與每日佛學小語，使用者可分類開關
- **法音梵唄**：唸佛機／持咒等音檔播放，支援背景播放與睡眠計時器
- **電子書**：經文與文章閱讀，支援字級、進度記憶與日夜間模式
- **交通資訊**：地圖、多種交通方式說明與一鍵導航

| 角色 | 說明 |

## 技術架構（建議）

實際選型將於技術評估階段確認。

```
┌─────────────────┐     ┌──────────────────────┐     ┌─────────────────┐
│  App 前端        │────▶│  後端 API Server      │────▶│  資料庫          │
│  iOS / Android  │     │  會員／查詢／內容等   │     │                  │
└─────────────────┘     └──────────┬───────────┘     └─────────────────┘
                                   │
              ┌────────────────────┼────────────────────┐
              ▼                    ▼                    ▼
       AI 分類服務           推播服務              雲端物件儲存
       （規則／ML／LLM）   （FCM／APNs）         （音訊／電子書／圖片）
                                   │
                          內容管理後台（CMS）
```

| 層級 | 建議方向 |
|------|----------|
| App 前端 | 原生（Swift／Kotlin）或跨平台（Flutter／React Native） |
| 後端 | 會員、業障查詢、AI、心得、推播、內容等 REST／GraphQL API |
| 推播 | Firebase Cloud Messaging、Apple Push Notification Service |
| 儲存 | AWS S3／GCP Cloud Storage 等物件儲存 |
| 網站整合 | 優先以 API／同步層銜接既有 CMS，避免雙邊重複維護 |

**平台建議**：iOS 15+、Android 10+

## 安全與隱私

- 密碼不可逆雜湊儲存；API 全程 HTTPS
- 個人業障資料嚴格授權控管
- 匿名心得前台去識別化，後台追溯僅限必要情境並留存查閱紀錄
- 首次註冊須取得隱私權政策與服務條款同意
- 建議支援帳號／個人資料刪除請求（個資法合規）
